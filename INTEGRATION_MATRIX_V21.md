# Integration Matrix — v2.1 Expansion

This supplements `INTEGRATION_MATRIX.md` for the v2.1 Profiles. All remain internal-only; no Profile gains user-channel binding merely from an integration listed here.

| Profile group | Integration posture |
| --- | --- |
| Product Manager / Business Analyst / COO / People Ops / Decision Scientist | Internal planning/analysis plus current web research where needed; no blanket account-write authority. |
| Recruiter | Current labor-market web research; no autonomous applications, candidate impersonation, employer-system writes, reference contact, or discriminatory screening. |
| Privacy / GDPR Specialist | Authoritative EU/regulator web research; no legal representation or direct production-system changes. |
| Negotiation & Conflict Resolution | Internal preparation and communication strategy; no contract, payment, legal-settlement, or external commitment authority. |
| Automotive Maintenance | Manufacturer/manual web research; no vehicle remote-control or physical repair authority; safety-critical work escalates. |
| Home Energy / Solar | Web/tariff/product research and modeling; mains/grid/battery installation and electrical execution remain regulated. |
| Water & Wastewater | Web/technical research; no potability certification or regulated installation authority. |
| Emergency Preparedness | Planning/checklists only; no implied emergency-services dispatch or external purchasing authority. |
| Arboriculture / Pest & Building Biology | Web/technical research; hazardous tree work, chemical application, substantial mold/infestation, and regulated work escalate. |
| Horticulture / Farm Machinery | Web/manual/agronomic research; no autonomous chemical purchasing/application or machine remote control. |
| Livestock Health Navigator | Husbandry/records/research only; no veterinary diagnosis, prescribing, drug ordering, or treatment authority. |
| Child Development / SEN / Teachers / Literacy | Education/research capability only; no health/clinical diagnosis and no learner-account access unless separately authorized. |
| Insurance | Policy research/comparison only; no binding, purchase, cancellation, claims submission, or insurer-account administration. |
| Estate & Succession | Research/planning only; no wills, filings, signatures, asset transfers, or legal representation. |
| Procurement & Vendor Manager | Web/vendor research and negotiation preparation; no autonomous purchase orders, payments, or contract signatures. |
| EU Law / Employment Law | Current authoritative legal-source research only; no legal representation, filings, or employer-account writes. |
| Network Engineer / SRE / Database Reliability | Technical tooling only on explicitly authorized systems; production changes remain host-authorized and scoped. |
| AI/ML Engineer | Codex + GitHub for reviewed engineering; deployment/data access remains explicitly scoped and privacy/security reviewed. |
| Privacy/Security Engineer | Technical review/implementation only on authorized systems; legal compliance conclusions remain with Privacy/Law specialists. |
| Fact Checker / Media Literacy | Web/source research and independent verification; no external account writes and no partisan advocacy. |
| Ethics Specialist | Internal normative analysis; no execution integration or authority over domain specialists. |
| Knowledge Manager / Archivist | Authorized documentation/knowledge stores only; private learned overlays retain no-export/no-auto-publish rules. |
| Catholic Relationship / Traditional Family / Tradition / History / Prayer Writer | Authoritative Catholic/historical web research where useful; no clergy, confessional, sacramental, canon-law, therapy, or family-account authority. |
| Portuguese ↔ English Translator | Document/text transformation only; no external-account writes and no claim of sworn/certified status. |
| Building Architect | Web/standards/design research; no statutory submission/sign-off, permit authority, or regulated professional impersonation. |
| Farm Planner | Internal planning + current agronomic/site research; purchasing, regulated works and financial commitments stay delegated. |
| 3D Model Designer | Codex/filesystem-compatible design tooling when provisioned; no physical-machine control by default. |
| 3D Printer Specialist / Model Maker / Model Optimizer | Process/manual/design research; printer execution or unattended physical control requires separate host authorization and safety policy. |

## Cross-domain rule

A data/research capability does not imply action authority. Web access does not imply purchasing, communications, account administration, physical control, statutory sign-off, legal representation, clinical/veterinary treatment, or financial execution.
