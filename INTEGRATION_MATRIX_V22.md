External access remains least-privilege and host-authorized. All Profiles are internal-only.

| Profile group | Default integration posture |
| --- | --- |
| HermesAgent Expert | GitHub + web research; repository/runtime observation only within delegated host access |

| Ancient-tradition specialists | Web research by default; reconstruction is informational, not automatic physical execution |
| Traditional Catholic specialists | Web/repository research only; no parish/diocesan account or ecclesiastical administration integration by default |
| General/specialized fitness coaches | No external account integration by default; optional user-provided training data may be scoped by host policy |
| Prenatal/postpartum fitness | No medical-record integration by default; clinician restrictions are user/professional supplied constraints |
| Youth fitness | No child account/external messaging integration by default; safeguarding remains authoritative |

No integration connection makes a Profile user-facing, transfers raw credentials into Profile context, or expands the capability granted by the host/runtime.
